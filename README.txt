## Sample Pseudocode: Decimal to Binary 

``` 
START
 INPUT "Enter a decimal number:",n
 IF n=0 THEN
  DISPLAY "0'
ELSE
 SET binary='"'
 WHILE n>0 DO
   SET remainder=n MOD 2
   SET binary=remainder + binary
   SET n=n DIV 2 
  ENDWHILE
  DISPLAY binary
 ENDIF
END

 
```
